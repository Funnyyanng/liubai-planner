# 交大 Canvas 接入

站点固定为 https://oc.sjtu.edu.cn。学校端仅调用 GET，不提交作业、不改选课或日历。

## 使用

1. 打开侧栏「Canvas」，点击「智能整理待办」。已保存令牌时无需再次输入。
2. 自动检查全部可访问课程，只把有未来未提交作业或未来 60 天日程的课程加入选择列表，按最早截止时间排序。
3. 未来待办自动勾选；确认预计用时后应用并重排。刷新当前课程可按需读取课件。
4. 无截止时间的未提交作业放入「待确认」，不会静默丢弃；读取失败课程单独报告，不视为没有待办。

已提交、被豁免和截止时间已过的作业默认隐藏。已有本地执行事实和历史记录不会因筛选而删除。

## 2026 年 5 月 5 日测试

关闭其他留白实例后，双击输出目录中的「启动留白测试-2026-05-05.command」。测试时钟固定在北京时间 2026-05-05 00:00，使用独立测试数据库；首页、任务编辑和排程采用相同时间，界面顶部显示测试横幅。macOS 系统时间不变。

直接打开「留白.app」仍使用真实时间和正常数据目录。测试启动器与应用需放在同一目录。

筛选会比较 Canvas 提交时间与测试时钟，但 Canvas 返回的是当前可访问记录；已修改的截止时间、已撤销的课程、缺少历史提交时间等无法由此完整还原。测试模式不是学校历史数据快照。

## 同步语义

- 第一版为用户触发、预览后应用的同步，未实现后台定时同步。
- 作业使用课程 ID 与作业 ID 作为稳定映射，重复同步不会新增副本。
- 已有任务保留本地标题、估时、剩余工作、依赖、完成标准和完成状态；选中同步时更新 Canvas 截止时间。
- 新任务估时由用户明确输入，不从分数或附件大小推断。完成标准保留原作业入口，完整要求在 Canvas 查看。
- 已提交／已评阅只作提示，不自动完成本地任务。
- 日历使用 Canvas 事件 ID 更新，情境模块的注意力设置独立保存。
- 同步事务同时保存外部记录与业务变化，失败整批回滚。提交检查本地输入版本，随后调用原有协调与重排流程。
- 本次响应中消失的记录不会自动删除，取消事件与远端删除的差异确认仍是后续功能。

## 模块与平台边界

`modules/canvas` 负责 API 数据转换、预览和本地合并规则；通过 `ExternalReader` 使用框架提供的网络能力。自身缓存保存在 `canvas_records`，任务／日历写入由协调器调用各模块公开函数完成。排程引擎没有增加 Canvas 专有判断。

框架负责钥匙串、HTTPS、超时、响应体大小、分页上限和凭据目的地校验。拒绝重定向和跨站分页地址；HTTP 错误不输出响应正文或令牌。课程文件接口不可用时允许作业继续预览；作业或日历失败则不返回可应用的部分结果。

令牌仅存于 macOS 钥匙串的 `local.student-planner` / `canvas:oc.sjtu.edu.cn` 项，不进入 SQLite、源码或交付压缩包。可以在 Canvas 撤销测试令牌，之后在应用内保存替代令牌。
